# Bundled fonts

Latin subsets from Google Fonts, served as WOFF2 and embedded by
`tavola.themes.fonts` as data URIs. Each family is licensed under the SIL Open
Font License 1.1; the licence text sits next to the font file.

| Family | File | CSS weight range | Source |
|---|---|---|---|
| Inter | `inter-latin.woff2` | 100–900 | <https://fonts.google.com/specimen/Inter> |
| Source Serif 4 | `source-serif-4-latin.woff2` | 200–900 | <https://fonts.google.com/specimen/Source+Serif+4> |
| Caveat | `caveat-latin.woff2` | 400–700 | <https://fonts.google.com/specimen/Caveat> |

The Google Fonts CSS API supplied the latin-subset files. System fallbacks in
each theme cover other scripts and older environments.
